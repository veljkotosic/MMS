# MMS

Desktop application for image processing, developed as a university project for the **Multimedia Systems** course.

## Getting Started

### Requirements

* .NET SDK
* IDE with .NET support

### Setup

1. Clone the repository:

```bash
git clone https://github.com/veljkotosic/MMS.git
cd MMS
```

2. Open `MMS.slnx` in Visual Studio or JetBrains Rider.

3. Build the solution.

4. Run the gRPC service.

5. Run the Wpf application.

The solution also contains the gRPC service, image-processing core, infrastructure, contracts, tests, and benchmark projects.
